# Turtle Soup System Management UI

Management client for Turtle Soup, based on the `saiadmin-artd` frontend from SaiAdmin 6.1.1.

## Development

```bash
pnpm install
pnpm dev
```

## Related branches

- `ui`: user-facing uni-app client
- `system-manage-ui`: SaiAdmin management client (this branch)
- `system-manage`: Webman backend, user API, WebSocket, and AI integrations
