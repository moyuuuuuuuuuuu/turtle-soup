# Turtle Soup UI

AI-powered turtle soup puzzle game client built with uni-app, Vue 3, TypeScript, and Wot UI.

## Targets

- H5
- WeChat Mini Program
- Future uni-app compatible platforms

## Development

```bash
pnpm install
pnpm dev:h5
```

For WeChat Mini Program development:

```bash
pnpm dev:mp-weixin
```

## Related branches

- `ui`: user-facing client (this branch)
- `system-manage-ui`: SaiAdmin management client
- `system-manage`: Webman backend, user API, WebSocket, and AI integrations

The project is initialized from [Wot Starter](https://github.com/wot-ui/wot-starter) and retains its MIT license.
